## 안녕하세요!

[Terraform](https://developer.hashicorp.com/terraform) 공식 문서 전체를 한국어로 번역하는 것을 목표로 하는 오픈소스 커뮤니티입니다. 원문은 [hashicorp/web-unified-docs](https://github.com/hashicorp/web-unified-docs)를 기준으로 하며, 누구나 문서 하나부터 부담 없이 기여할 수 있습니다.

## 프로젝트

| 저장소                                                                    | 설명                                            | 상태     |
| -------------------------------------------------------------------------- | ----------------------------------------------- | -------- |
| [terraform-ko](https://github.com/terraform-ko/terraform-ko)               | `developer.hashicorp.com/terraform` 문서 번역    | 진행 중  |
| terraform-registry-ko                                                       | `registry.terraform.io` 문서 번역                | 준비 중  |

## 기여하고 싶다면

1. [terraform-ko](https://github.com/terraform-ko/terraform-ko) 저장소를 포크합니다.
2. [CONTRIBUTING.md](https://github.com/terraform-ko/terraform-ko/blob/main/CONTRIBUTING.md)에서 이슈 할당 방법과 번역 절차를 확인합니다.
3. [STYLE_GUIDE.md](https://github.com/terraform-ko/terraform-ko/blob/main/STYLE_GUIDE.md)의 어조·용어 규칙을 따라 번역하고 PR을 보냅니다.

번역이 아니어도 사이트(Next.js + Nextra) 기능 개선, 오탈자 제보, 스크립트 버그 수정 등 모든 기여를 환영합니다.
